# processing-COG

> **Archived — no longer maintained.**
>
> This plugin only imported the INSEE list of foreign countries and territories
> (`pays_<year>.csv` of the Code Officiel Géographique). It was never published on npm nor on the
> data-fair registry, and has not been maintained since 2022.
>
> Its output dataset (`codes-officiels-geographiques` on koumoul.com) was deleted on 2026-10-19.
> Its only consumer, [processing-deaths](https://github.com/data-fair/processing-deaths), now ships
> the INSEE country list itself (`lib/countries.json`, current list and list since 1943).
>
> For communes, see [processing-cogAPI](https://github.com/data-fair/processing-cogAPI) and
> [processing-history-cog](https://github.com/data-fair/processing-history-cog).
